Проект: Система управления мобильным роботом на STM32F411RE

Описание проекта

Проект представляет собой систему управления мобильным роботом на базе микроконтроллера STM32F411RE. Робот предназначен для движения по линии

Параметры робота

    Базовый ШИМ: 400 единиц

    Максимальный ШИМ: 1000 единиц

Конфигурация:

    PA0, PA1, PA4 - Датчики линии TCRT-5000
    PA5, PA6, PA7, PB6 - Моторы
    PB3, PB10 - Выходы управления скважностью
    PC13 - Кнопка запуска/останова
    PC2 - Индикационный светодиод

Архитектура:

    |__. main.c - Логика прохождения по линии
    |__. init.c - Инициализация GPIO, настройка тактирования, системный таймер, продвинутый таймер
    |__. interrupt.c - Обработка прерываний по кнопке
    |__. motor.c - Логика управления моторами
    |__. sensors.c - Логика работы датчиков
